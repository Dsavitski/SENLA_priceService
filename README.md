# Price Service

Микросервис на **Java 21** и **Spring Boot 3** для автоматизированного сбора, хранения и анализа криптовалютных котировок. Приложение периодически опрашивает API Binance (по умолчанию `BNBUSDT`), сохраняет данные в **PostgreSQL** и предоставляет **REST API** для получения актуальных цен, истории с пагинацией, расчета средних значений и определения трендов.
## 🛠 Технологии

- **Java 21**
- **Spring Boot 3.3.5** (Web, Data JPA, Validation, Actuator, Scheduling)
- **PostgreSQL 15** + **Liquibase** (версионирование и миграции БД)
- **Docker & Docker Compose** (контейнеризация приложения и окружения)
- **Testcontainers** (изолированное интеграционное тестирование)
- **SpringDoc OpenAPI** (интерактивная документация API / Swagger UI)
- **MapStruct & Lombok** (маппинг DTO и сокращение boilerplate-кода)

## 🔌 API Эндпоинты

Сервис предоставляет 4 основных REST-эндпоинта для работы с данными (базовый путь: `/api/v1/prices`):

1. **`GET /latest`** — Возвращает самый свежий зафиксированный срез цены для указанного символа (по умолчанию `BNBUSDT`).
2. **`GET /average`** — Рассчитывает и возвращает среднее арифметическое значение цены за заданный временной интервал (параметры `from` и `to`).
3. **`GET /`** — Возвращает постраничный список (пагинация) исторических записей цен за указанный период (параметры `page`, `size`, `from`, `to`).
4. **`GET /trend`** — Анализирует динамику цен за указанный период и возвращает статус тренда: `UPWARD` (рост), `DOWNWARD` (падение) или `FLAT` (без существенных изменений).

> 💡 Полная интерактивная документация со всеми параметрами запросов доступна по адресу: `http://localhost:8080/swagger-ui.html`

## ⚙️ Переменные окружения

Сервис поддерживает настройку через переменные окружения или файл `.env` (при использовании Docker Compose).

| Переменная | Описание | Значение по умолчанию / Пример |
| :--- | :--- | :--- |
| `DB_NAME` | Имя базы данных | `priceservice` |
| `DB_USER` | Пользователь базы данных | `postgres` |
| `DB_PASSWORD` | Пароль пользователя БД | `your_secure_password` |
| `DB_URL` | JDBC URL для подключения к БД | `jdbc:postgresql://postgres:5432/priceservice` |
| `BINANCE_API_URL` | Базовый URL API Binance | `https://api.binance.com/api/v3` |
| `BINANCE_POLL_INTERVAL` | Интервал опроса API (ISO-8601 Duration) | `PT30S` (каждые 30 секунд) |
| `BINANCE_DEFAULT_SYMBOL` | Торговая пара по умолчанию | `BNBUSDT` |
| `SPRING_PROFILES_ACTIVE` | Активный профиль Spring | `docker` |
